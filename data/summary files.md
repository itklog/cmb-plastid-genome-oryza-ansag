### Download Instructions
To fetch the sequence files locally via command line, execute:

```bash
# Download FASTA file
curl -o data/NC_001320.1.fasta "[https://www.ncbi.nlm.nih.gov/sviewer/viewer.fcgi?db=nuccore&report=fasta&id=NC_001320.1](https://www.ncbi.nlm.nih.gov/sviewer/viewer.fcgi?db=nuccore&report=fasta&id=NC_001320.1)" 
# Download full GenBank flat file with annotations
curl -o data/NC_001320.1.gb "[https://www.ncbi.nlm.nih.gov/sviewer/viewer.fcgi?db=nuccore&report=gbwithparts&id=NC_001320.1](https://www.ncbi.nlm.nih.gov/sviewer/viewer.fcgi?db=nuccore&report=gbwithparts&id=NC_001320.1)"
